# Final Demo Checklist

## Before Recording

- Endpoint instance is running.
- Endpoint verification passes.
- Default profile backup exists.
- Terminal size and font are readable.
- `FORCE_COLOR=1` is enabled.
- API key is not visible.
- Private endpoint URL is not visible.
- Benchmark report is final and non-mock.
- Radeon evidence screenshots are ready.

## Recording Sequence

1. Show project name and architecture.
2. Show Radeon endpoint verification.
3. Show real default-profile status.
4. Enter the natural-language goal.
5. Show tool timeline.
6. Answer one correct and one incorrect.
7. Request etymology.
8. Show adaptive generated passage.
9. Show English and Chinese highlighting.
10. Show session summary.
11. Show performance summary.
12. Show thinking-mode benchmark table.

## After Recording

- Confirm no credentials are visible.
- Confirm no private endpoint URL is visible.
- Confirm the video length is 3-5 minutes.
- Confirm all links work.
- Confirm README numbers match benchmark JSON.
- Confirm no mock data is presented as real data.
