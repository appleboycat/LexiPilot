# Radeon Evidence

This directory is reserved for user-captured evidence from the real AMD Radeon
deployment. Do not add fabricated screenshots or inferred hardware values.

Before adding an artifact:

1. Crop or redact API keys, bearer tokens, private endpoint URLs, account IDs,
   private IP addresses, and unrelated personal information.
2. Do not show the private vocabulary PDF or real learner history.
3. Keep the original timestamp when practical.
4. Record the filename and use in `evidence_manifest.md`.

Recommended filenames are listed in the manifest. No screenshot is required for
the source repository to run its automated tests.
